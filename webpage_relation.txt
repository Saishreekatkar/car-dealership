HTML and CSS3 – Theory with Webpage Relation (AutoDeal Project)

1. HTML (HyperText Markup Language): The Structure
In the AutoDeal project, HTML acts as the skeleton that defines the content and semantic layout of the webpage.

- <header> & <nav>: Used at the top of all pages (like index.html and products.html) to structure the navigation bar containing the logo ("AutoDeal") and page links.
- <section>: Used to segment different functional areas of the site, such as the Hero display ("Find Your Dream Car Today") and the "Featured Vehicles" block.
- <img>: Embeds visual media, including all the vehicle images (like fridge.jpg, sedan.jpg) inside the vehicle cards, as well as the newly generated 3D UI icons (heart, cart, battery, engine).
- Forms (<select>, <input>, <label>): Used extensively in products.html to build the interactive "Filter Vehicles" sidebar, allowing users to select price ranges, vehicle types, and fuel types.
- <footer>: A semantic tag placed at the bottom to neatly wrap customer support links, contact numbers, and copyright text.
- Headings & Paragraphs (<h1>, <h2>, <p>): Establish typography hierarchy, putting emphasis on titles like "Why Choose AutoDeal".

2. CSS3 (Cascading Style Sheets): The Design
CSS3 acts as the design layer, providing the AutoDeal project with a modern, dynamic, and premium appearance.

- Advanced Selectors: Used efficiently, such as `.card:hover` to apply styles when the mouse is over a vehicle card, and `::after` on `.nav-links a` to build a sliding underline animation on hover.
- Responsive Design (Media Queries): The `@media (max-width: 768px)` rule makes the project mobile-friendly by stacking navigation items vertically and converting the vehicle grid to a single column on smaller screens.
- Flexbox and Grid: `display: flex;` is used heavily to center and align navigation items and card actions. `display: grid;` and `grid-template-columns` create the structured grid layout (`.cards-grid`) that elegantly holds the vehicle listings.
- Animations and Transitions: `@keyframes fadeInUp` animates the hero text so it slides upward and fades in when the page loads. `transition` ensures color changes and transforms happen smoothly instead of instantly.
- Colors & Typography: Incorporates custom CSS Variables in `:root` (e.g., `--primary-color: #1a56db`) for consistent theming. RGBA is used selectively for semi-transparent elements like shadows.
- Box Model Enhancements: Elements like `.card` utilize `border-radius: 12px;` for modern rounded corners and `box-shadow` for varying depths, giving elements a lifted, card-like feel.
- Gradients: A `linear-gradient` is applied as the background to the main `.hero` section to create an eye-catching visual instead of a flat color.
- Transforms: `transform: translateY(-5px);` physically moves the vehicle cards slightly upward on hover, adding an interactive micro-animation.

3. Combined Working (Practical Application)
- Structure + Style = Webpage: Without HTML, there is no text saying "Browse Our Inventory" and no buttons to click. Without CSS3, the website would just be a top-to-bottom unstyled black-and-white word document.
- In AutoDeal: HTML builds the container (`<div class="card">`) and text (`<h3 class="card-title">2024 Compact SUV</h3>`), and CSS3 converts that basic text container into a beautiful floating white card with a subtle drop shadow, aligned neatly within a symmetrical layout, providing your dealership with a premium feel.
